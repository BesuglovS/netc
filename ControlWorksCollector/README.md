# ControlWorksCollector — сбор контрольных работ с рабочих столов учеников

Локальное Windows-приложение (C# WinForms, .NET Framework 4.8) для учителя.
Забирает папки с рабочих столов ученических ПК (Windows 10/11) по локальной
сети Wi‑Fi через админ-шару `C$` по SMB. Агент на ученических ПК не требуется.

## Как это работает

1. Приложение на ПК учителя подключается к каждому ПК из списка под локальным
   администратором (`\\ПК\C$`).
2. Перебирает профили в `C:\Users` и берёт рабочие столы учеников:
   `C:\Users\<ученик>\Desktop` (и, при желании, общий `Public\Desktop`).
   Перенаправленные в OneDrive рабочие столы не используются.
3. Отбирает **только папки верхнего уровня**, созданные в выбранную дату
   (по умолчанию — сегодня).
4. Копирует их локально в структуру:

   ```
   <папка сохранения>\ГГГГ-ММ-ДД\<папка> (IP)
   ```

   Все папки собираются в одну папку за дату; к имени каждой папки
   добавляется IP-адрес компьютера-источника, например `Попов 1 (10.12.6.10)`.

## Требования

- ПК учителя: Windows 10/11 с .NET Framework 4.8 (предустановлен).
- Ученические ПК: Windows 10/11, включённый, доступен по сети.
- Единая локальная учётная запись администратора на всех ученических ПК.
- На ученических ПК включён общий доступ к файлам (порт SMB 445) — см. раздел
  «Подготовка ученических ПК».
- Точка доступа Wi‑Fi **без изоляции клиентов** (иначе ПК не видят друг друга).
- ПК учителя и учеников в одной подсети.

## Сборка

Откройте PowerShell в каталоге проекта и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат: `bin\ControlWorksCollector.exe`.

Компиляция идёт через Roslyn (`csc.exe`) из Build Tools/Visual Studio, с запасным
вариантом — встроенный в Windows компилятор. Целевая платформа — .NET Framework 4.8,
поэтому готовый exe запускается без установки чего‑либо.

Запустить сразу после сборки:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Run
```

## Настройка и использование

1. Запустите `bin\ControlWorksCollector.exe`.
2. Нажмите **«Настройки»** и заполните:
   - **Папка для собранных работ** — куда складывать работы (локально на ПК учителя).
   - **Пользователь-администратор** и **Пароль** — единая локальная админ-учётка
     ученических ПК. Пароль можно сохранить (шифруется DPAPI под текущего
     пользователя Windows) или вводить каждый раз.
   - **Таймаут, сек** — ожидание недоступного ПК.
   - **ПК одновременно** — сколько машин обрабатывать параллельно (по умолчанию 4).
   - **Что собирать** — общий рабочий стол `Public\Desktop` (по желанию).
   - **Список компьютеров** — таблица с полями: **Название**, **Имя ПК**, **MAC**,
     **IP**, **Примечание**.
3. Сохраните настройки. В главном окне выберите **дату сбора** (по умолчанию сегодня)
   и нажмите **«Собрать сейчас»**.
4. Следите за статусом в таблице и журнале внизу окна. Кнопка **«Открыть папку сборов»**
   открывает каталог с результатами.

### Инвентарь ПК (устойчивость к смене адресов)

Для каждого ПК хранятся имя компьютера и MAC, а IP — как «последний известный».
При сборе ПК сначала ищется по IP, а если он недоступен — по имени компьютера,
поэтому смена IP не ломает сбор (если имя уникально).

Собираются только папки с обычного рабочего стола ученика
(`C:\Users\<ученик>\Desktop`). Перенаправленные в OneDrive рабочие столы
не используются.

Кнопки над таблицей:

- **Добавить** — новая строка;
- **Удалить выбранные**;
- **Вставить список IP…** — быстро добавить много адресов (по одному в строке);
- **Определить имя и MAC** — приложение подключится к каждому ПК и заполнит поля
  «Имя ПК» и «MAC» (нужны логин/пароль; используется `IPC$`).

Список хранится в `%AppData%\ControlWorksCollector\config.json`.
Старый формат (`ips.txt`) автоматически переносится в инвентарь при первом запуске.

> Примечания: MAC определяется только для ПК в той же подсети, что и компьютер
> учителя (ограничение ARP). Имя компьютера может совпадать у ПК, склонированных
> без sysprep — в этом случае ориентируйтесь на IP и MAC.

Текущая установка уже настроена:

- 19 ПК в инвентаре (имена и MAC заполнены);
- учётная запись: `MNU`;
- папка сохранения: `C:\admin\files\Сборы`.

## Подготовка ученических ПК

На **каждом** ученическом ПК запустите от имени администратора:

```powershell
powershell -ExecutionPolicy Bypass -File .\Prepare-StudentPc.ps1
```

Скрипт включает правила брандмауэра для SMB (TCP 445), запускает службу
«Сервер» (LanmanServer), проверяет шару `C$` и показывает локальных администраторов.

Дополнительно можно задать пароль админа и добавить его в группу администраторов:

```powershell
powershell -ExecutionPolicy Bypass -File .\Prepare-StudentPc.ps1 `
    -AdminUser Administrator -Password "P@ssw0rd!" -EnableAdmin -PasswordNeverExpires
```

Проверка доступности с ПК учителя (для конкретного ПК):

```powershell
Test-NetConnection PC-01 -Port 445
```

Ручная проверка/настройка (если скрипт недоступен):

```powershell
Enable-NetFirewallRule -Group "@FirewallAPI.dll,-28502"
Set-Service LanmanServer -StartupType Automatic
Start-Service LanmanServer
```

## Структура результата

```
Сборы\
└── 2026-10-08\
    ├── Контрольная работа №3 (10.12.6.10)\   (папка с рабочего стола ученика)
    ├── Проект (10.12.6.12)\
    └── Домашнее задание (10.90.3.38)\
```

Все папки за дату лежат в одном каталоге. К имени папки добавляется IP-адрес
компьютера-источника. Если имена всё же совпадают, добавляется уточняющий
суффикс, чтобы ничего не потерять.

## Устранение неполадок

| Симптом | Причина / решение |
|---|---|
| Статус «Недоступен» | ПК выключен или в другой сети; проверьте `Test-NetConnection PC -Port 445`. |
| «Неверный логин или пароль» (1326) | Проверьте учётные данные в настройках. |
| «Доступ запрещён» (5) | Учётка не входит в локальные администраторы **или** включена UAC-фильтрация сетевого токена. Запустите `Prepare-StudentPc.ps1` на этом ПК (он ставит `LocalAccountTokenFilterPolicy=1`). |
| «Сетевое имя не найдено» (67) | Отключена шара `C$` или служба LanmanServer. |
| «Сетевой запрос отклонён» / конфликт (1219) | На ученике уже есть сессия под другим пользователем, либо включена изоляция клиентов Wi‑Fi. |
| ПК не видят друг друга | Отключите изоляцию клиентов на точке доступа Wi‑Fi. |
| Пароль не расшифровывается | Файл конфигурации сохранён другим пользователем Windows; введите пароль заново. |

Логи: `%AppData%\ControlWorksCollector\logs\collect-YYYYMMDD.log`.
Конфигурация: `%AppData%\ControlWorksCollector\config.json`.

## Безопасность

- Пароль хранится только в зашифрованном виде (DPAPI, привязка к учётной записи
  Windows учителя). Ключ «Сохранять пароль» можно снять — тогда пароль спрашивают
  при каждом сборе.
- Приложение работает без прав администратора на ПК учителя; права админа нужны
  на ученических ПК (для доступа к `C$`).
- Передаваемые по сети учётные данные защищены как обычно в SMB (в рабочей группе
  без подписывания — используйте доверенную школьную сеть).

## Ограничения

- Собираются только папки, созданные в выбранную дату (по условию задачи).
  Отдельные файлы на рабочем столе не копируются.
- Требуется, чтобы ученический ПК был включён в момент сбора (Wake‑on‑LAN по
  Wi‑Fi обычно недоступен).
- Очень длинные пути могут не копироваться в редких случаях; используйте
  короткие имена папок.
