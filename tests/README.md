# Файлы тестов для netc (из квизов python-web)

Готовые тесты для окна **«Тест»** учительского клиента (`dist\client\NetcClient.exe`).
Сгенерированы из квизов проекта `C:\websites\na\python-web\quizzes`.

## Что здесь

| Файл | Содержимое |
|---|---|
| `urok-01.json` … `urok-50.json` | по 10 вопросов на урок (уроки 1–50) |
| `itogovyy.json` | итоговый тест, 50 вопросов |
| `convert_quizzes.py` | конвертер (пересоздать при обновлении квизов) |

Всего **51 файл, 550 вопросов**. Тип вопросов — «Один вариант» (как в исходных квизах).

## Настройки сгенерированных тестов

- режим: один вариант ответа, 1 балл за вопрос;
- **перемешивание** вопросов и вариантов — включено;
- показ результата ученику — включён;
- **проходной балл 70 %**;
- **лимит времени 0** (без ограничения — задайте в редакторе при необходимости);
- PIN аварийного выхода — пусто.

Всё это меняется в окне «Тест» после импорта.

## Как использовать

1. Запустить `dist\client\NetcClient.exe` (учитель).
2. Кнопка **«Тест»** → выбрать ПК → **«Импорт JSON»** → выбрать нужный файл.
3. При необходимости поправить параметры/вопросы.
4. **«Отправить тест»**; досрочно — **«Завершить тест»**.

> Импорт заменяет текущий список вопросов в окне. Перед импортом другого теста сохраните нужное
> («Экспорт JSON»).

## Пересоздать файлы (после правок квизов)

```powershell
python C:\admin\files\tests\convert_quizzes.py
```

Скрипт читает `C:\websites\na\python-web\quizzes\*.json` и `lessons.json` (названия уроков),
убирает HTML-теги (`<code>…</code>` → текст) и раскрывает сущности (`&lt;` → `<`).
`id` тестов детерминированный (одинаковый при повторной генерации).
