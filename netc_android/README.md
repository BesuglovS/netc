# netc_android — пульт учителя на планшете Android

Android-приложение для управления компьютерами учебного класса тем же протоколом, что и
десктопный `netc_client`. Планшет подключается по Wi-Fi к той же сети, что и ученические ПК,
и общается с агентами напрямую (TCP 7801, UDP 7802).

## Технология

- **C# / .NET for Android** (`net10.0-android`, API 36), проект `netc_android/NetcAndroid.csproj`.
- Протокол, шифрование и сетевая логика **переиспользуются** из библиотеки `netc_shared`
  (`NetcShared`): `Protocol`, `Crypto`/`SecureChannel`, `NetcClientCore`, `ScreenClient`, `Wol`.
- Интерфейс — нативные Android-виджеты без внешних зависимостей.
- Раскладка адаптивная: на большом экране (планшет) — две панели (список ПК + журнал/статус),
  на узком — вертикально.

## Требования

- Планшет Android 8.0+ (API 26), arm64-v8a. Проверено на **Xiaomi Pad 7** (Android 16, API 36).
- Для сборки: .NET SDK 10 + workload `android` (`dotnet workload install android`),
  Android SDK (platform `android-36`), JDK 17.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build-android.ps1
```

Результат: `dist\android\NetcAndroid.apk` (подписан релизным ключом `netc_android\keystore\netc.keystore`).

## Установка на планшет

1. На планшете включить «Для разработчиков» и **«Установка через USB»**
   (на HyperOS/MIUI это обязательный переключатель, без него `adb install` даёт
   `INSTALL_FAILED_USER_RESTRICTED`), плюс «Отладку по USB».
2. Подключить планшет по USB и поставить:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-android.ps1 -Install -Device <серийный-номер>
```

Серийный номер — из `adb devices`. Либо установить `dist\android\NetcAndroid.apk` вручную
(скопировать на планшет и открыть).

## Настройки и сеть

- При первом запуске список сразу заполняется известными 24 ПК класса (адреса и имена
  `R114-01…24`, модели) — как в десктопном клиенте.
- **«Обнаружить»** — поиск агентов в своей подсети по UDP (нужен `MulticastLock`, планшет
  берёт его автоматически). Класс распределён по нескольким подсетям (`10.12.6.x`, `10.90.x`,
  `10.99.4.x`), поэтому основной путь — список IP, а обнаружение — дополнение для своей подсети.
- **«Обновить сведения»** — параллельные подключения к агентам: имя ПК, пользователь, модель, ОС.
- Общий ключ и порты — в **«Настройках»** (SharedPreferences), должны совпадать с агентами.

## Текущий статус

**Фаза 1 (готово, проверено на планшете):** каркас проекта, переиспользование `netc_shared`,
главный экран со списком ПК, обнаружение, «Обновить сведения» (на Xiaomi Pad 7 ответили все 24 ПК),
добавление/удаление ПК, настройки, сохранение списка и MAC. Раскладка адаптивная: на планшете
(ландшафт) — две панели (список + журнал/статус), в портрете — вертикально.

**Фаза 2 (готово, проверено на планшете):**
- **Стена экранов** — живые миниатюры ПК (3 колонки в ландшафте), авто-переподключение плиток,
  тап по плитке открывает управление.
- **Удалённое управление** — поток экрана 1280px, мышь по касанию (нормированные координаты
  0..65535, учёт letterbox), прокрутка двумя пальцами, экранные клавиши (ПКМ, Esc, Tab, Enter, ⌫,
  стрелки, Win, Alt+Tab, Ctrl+Alt+Del) и поле ввода текста (символы уходят на ПК).
  Экраны стены и управления принудительно ландшафтные (экран ПК 16:9).

**Фаза 3 (готово, проверено на планшете):**
- **Питание** (выключить/перезагрузить/завершить сеанс, задержка, подтверждение).
- **Сообщение** ученикам с ожиданием ответа — проверено: разослано на 24/24 ПК.
- **Блокировка экранов** — проверено визуально: все ПК показали «Экран заблокирован учителем»,
  снятие — при закрытии экрана/приложения (соединения с агентами удерживаются открытыми, иначе
  агент снимает оверлей; см. `AgentConnectionPool`).
- **Журнал** — проверено: получены записи со всех 24 ПК.
- **Ограничения**: приложения (чёрный/белый список), интернет (блокировка + закрытие браузеров),
  фильтр сайтов (домены), проверка автозагрузки.
- **Закрыть окна** (мягко/принудительно, Проводник), **Файлы** (отправить через SAF / забрать),
  **Включить** (Wake-on-LAN по MAC из «Обновить сведения»).

Каждое окно действия сверху содержит полосу выбора целевых ПК («Выбрать ПК…», «Все», «Никто»,
«выбрано N из M») — как в десктопном клиенте.

**Далее:** Фаза 4 — тесты (редактор 7 типов вопросов, отправка, результаты, CSV) и персонализация
(обои, экран блокировки, тема, акцент).

**Фаза 4 (готово, проверено на планшете):**
- **Тесты** — `TestActivity` + `QuestionEditorActivity`: составление вопросов всех 7 типов
  (`Single/Multi/TrueFalse/ShortText/Numeric/Essay/Matching`), параметры (таймер, перемешивание,
  показ результата, проходной %, PIN), импорт/экспорт JSON и экспорт результатов в CSV (через SAF),
  отправка теста и досрочное завершение, таблица результатов (ПК · ученик · баллы · % · время · итог).
  Живая проверка: тест на 24 ПК, ученики отвечали (3 сдали на 100%), затем снятие учителем
  и сбор результатов.
- **Персонализация** — `PersonalizationActivity`: обои (картинка + режим), экран блокировки,
  тема, акцент (палитра), сброс к стандартным.

Дополнительно: главный экран умеет открывать нужный раздел по параметру запуска
(`adb shell am start … --es open test|pers|screens|…`).

**По приложению в целом Фазы 1–4 закрыты.** Осталось ручное подтверждение: применение
персонализации (обои/тема/акцент), импорт теста из JSON (файлы `tests\urok-*.json`) и экспорт CSV.

## Установка (HyperOS/MIUI)

На Xiaomi/HyperOS `adb install` блокируется (`INSTALL_FAILED_USER_RESTRICTED`), пока в
«Для разработчиков» не включено **«Установка через USB»**. После включения установка идёт нормально:
`build-android.ps1 -Install`.
